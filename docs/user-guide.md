# 使用指南

## 账号与连接

官网：https://melatonin.claimclaw.org/

运营管理员入口：https://melatonin.claimclaw.org/admin

桌面服务地址：`https://melatonin.claimclaw.org`，不包含 `/admin` 或 `/api`。管理员负责模型配置、律所邀请、期限与额度；律师在网站完成邮件邀请激活，再在桌面「设置 → 通用 → 律所账号」选择「通过浏览器登录」并在浏览器中确认授权。管理员账号与律师使用账号职责不同。

从 v0.1.0-beta.34 起，安装包首次启动默认连接本站。旧版本已保存的地址会继续保留。需要指定其他地址时，可由启动环境变量 `MELATONIN_SERVICE_URL=https://melatonin.claimclaw.org` 指定服务地址，后续正常启动会记住地址。若打开软件后仍连接本机服务，请联系分发该安装包的管理员协助配置。

从 v0.1.0-beta.35 起，账号使用浏览器授权。旧客户端会提示升级；请安装新版本后重新登录，已有案件、材料和成果保留。邀请激活、找回密码、额度及设备授权管理均在网站完成。桌面可通过「打开用户中心」访问这些功能。取消或超时后可重新发起登录。

## 项目与对话

项目对应案件。添加一个普通文件夹即可，不要求 Git。同一项目下可创建多个对话，分别进行事实梳理、证据分析和文书起草；项目的材料、事实和成果在这些对话间共用。

材料、事实、成果位于顶栏「案件材料与成果」侧面板。原有对话列表、输入框与工具时间线继续用于安排和追踪工作。

## 导入和核对材料

支持 PDF、DOCX、PNG/JPEG、TXT/MD/CSV/TSV 与文件夹导入。当前单份 PDF 最多 250 页，单次最多导入 500 个文件。将材料用途设为案件材料、法律资料或文书模板，避免混淆本案事实与参考内容。

图片与扫描 PDF 需要管理员配置支持图像的模型。OCR 文字需要结合原图核对。点击对话或成果中的数字引用可查看来源。

## 分析、修改与交付

在对话中提出明确要求，例如：

> 请核对全部材料，保存事实时间线、案情分析、证据目录和待补材料清单。标明缺失与矛盾，并附原文引用。

律师可以修正或确认事实，修改记录会保留。起草时可提供模板，缺少必要信息会要求标记待补充。成果支持正文编辑、选中片段改写、版本切换、复核标记和 DOCX/PDF 导出。新增材料或修正事实后，应重新核对旧成果。

模型生成的内容是待复核草稿。有效引用标识不代表法律结论已被验证，法条依据与最终交付仍由律师核对。

## 设置和数据

语言、外观、通知、技能与原有设置一致；桌面端不提供模型选择与密钥配置，模型由后台统一管理。模型不可用、账号停用或额度不足时联系管理员。

每个对话任务、分析、起草/改写或单页 OCR 使用一次任务额度，同一任务的模型续调用不重复扣费。开始后失败或取消的任务仍计入额度；额度不等于模型供应商费用。

案件原件副本、事实、成果及对话历史保存在本机。推理所需内容会经后台转发给配置的模型服务，后台不保存请求或响应正文。本机保存不代表离线推理。当前不提供团队案件同步；账号切换也不等于整套桌面历史隔离。
