# Melatonin 0.1.0-beta.34 — macOS Apple Silicon 测试版

这是首个公开下载的测试预发行版，适用于 **Apple Silicon（M1/M2/M3/M4 等）Mac**。本次没有 Windows、Intel Mac 或 Linux 安装包。

## 下载与安装

- `melatonin-0.1.0-beta.34-arm64.dmg`：打开磁盘映像，将 `melatonin.app` 拖入 Applications。
- `melatonin-0.1.0-beta.34-arm64.zip`：ZIP 形式的相同应用，解压后放入 Applications。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

**签名状态：本版仅有 ad-hoc 签名，未使用 Apple Developer ID 签名，也未完成 Apple 公证。** macOS 可能阻止首次启动。请在确认下载来源和校验值后，按 macOS 显示的安全提示决定是否允许打开；不要将本版用于要求正式签名分发的部署。正式签名发行将在相应版本说明中另行标明。

## 开始使用

首次安装默认连接 `https://melatonin.claimclaw.org`，无需运行本地后台或安装 Node.js。

在「设置 → 通用 → 律所账号」使用已有账号登录，或凭管理员提供的邀请码激活。模型由后台统一管理。旧版本已经保存过其他服务地址的用户会继续保留原地址，可让管理员协助更新连接。

添加项目文件夹建立案件，在项目下创建对话；通过顶栏「案件材料与成果」导入材料、填写案件信息，并在对话中安排分析、起草和核对任务。

## 本版功能

- 原有项目 / 对话层级及语言、主题、外观和通知设置。
- 案件材料、法律资料与文书模板分类，PDF/DOCX/图片/文本导入。
- 原文引用、事实修正、案情分析、时间线、证据目录及待补材料清单。
- 文书初稿、片段改写、成果版本和律师复核，DOCX/PDF 导出。
- 后台统一模型、邀请账号、试用期限与任务额度。

## 已知范围

模型输出和 OCR 文字需要律师复核。材料保存在本机；推理所需内容会经后台发送给配置的模型服务。本版不提供团队案件同步、客户门户、权威法规/案例库或支付。

当前 macOS 界面与打包检查通过；这不代表 Windows/Word/WPS 或真实卷宗法律质量验收。账号测试中的登录流程与原生钥匙串授权是不同检查，macOS 可能单独请求凭据存储权限。

公开仓库和 GitHub 自动生成的 “Source code” 压缩包仅含使用说明、版本说明与版权声明。请下载上述 DMG/ZIP 安装附件，而不是 “Source code”。
