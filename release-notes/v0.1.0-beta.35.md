# Melatonin 0.1.0-beta.35 — 浏览器登录升级

新版账号服务需要 **v0.1.0-beta.35 或更新客户端**。请安装后重新登录；原有本地案件、材料、成果和对话记录保留。

## 登录与账号管理

1. 已有用户保留原账号和密码。新用户先通过管理员发送的邮件，在网站激活账号。
2. 在桌面「设置 → 通用 → 律所账号」点击「通过浏览器登录」。
3. 在浏览器登录网站并确认对 Melatonin 桌面的授权，完成后返回桌面。

授权支持取消、超时后重试和设备撤销。桌面「打开用户中心」可查看额度、使用记录和已授权设备；密码找回在网站完成。旧客户端的密码登录接口已停用，请从本公开发行仓库升级。

## 验证与使用范围

macOS 已通过真实 Electron、浏览器授权、账号切换、刷新令牌轮换、设备撤销及重新授权后恢复原成果的检查。模型配置继续由管理员统一管理；本版不更换供应商或账号的既有额度。

材料和对话保存在本机，推理所需内容经后台发送到管理员配置的模型服务。模型与 OCR 输出仍需律师复核。当前不包含团队案件同步、云端办案、支付或第三方账号登录。
